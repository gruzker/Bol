# Security reporting

Do not post API keys, private audio, transcripts, or exploitable security
details in public issues.

This repository is being prepared for publication. A private reporting
channel has not been configured yet. Before the public launch, the maintainer
must enable GitHub private vulnerability reporting under the repository's
security settings. Once enabled, use **Security > Report a vulnerability**.

Include the affected version, reproduction steps, impact, and a minimal
example containing no personal data. No response-time commitment or formal
security support policy is currently offered.

Bol sends real dictation audio to OpenRouter and its provider. The MIT
license does not govern those services. See the README for local storage
and data-flow details.
